# Privacy Policy — scioj tools

Last updated: 2026-11-16

## What these tools are

"scioj tools" are personal automation tools operated by a single
individual (the owner) to manage the owner's own accounts and data,
for example uploading the owner's own videos to the owner's own
YouTube channel via the YouTube Data API.

## Data accessed

The tools access only data belonging to the owner, under OAuth scopes
the owner personally grants (currently: YouTube account access for
uploading and managing the owner's own videos).

## Data use and sharing

- Accessed data is used solely to perform the owner's own tasks.
- No data is sold, rented, or shared with any third party.
- No data is used for advertising or profiling.

## Data storage

OAuth tokens and any working data are stored only on the owner's own
computers/servers, protected by file permissions, and are not
transmitted anywhere except to the respective Google API endpoints.

## Revocation and deletion

The owner can revoke the tools' access at any time from the Google
Account permissions page (https://myaccount.google.com/permissions).
Revocation immediately stops all API access. Stored tokens can be
deleted by the owner at any time.

## Contact

Questions can be raised via this repository's issue tracker.
